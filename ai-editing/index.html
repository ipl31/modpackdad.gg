How to use the ZIP

  1. Download and extract it. Use “Extract All” on Windows or double-click the ZIP on macOS. Open the extracted short-video-starter-2026-10-29 folder that contains START-HERE.md, AGENTS.md, and workflows/. Keep these files together.
  2. Choose Claude Code or Codex. Install and sign in to either one using the official guides below. You only need one. Open the extracted folder as your local project, or launch its terminal command from that folder.
  3. Send the starter prompt below. The agent will read the package, ask about your recording and preferences, and check the tools on your computer. You’ll need Python 3.10 or newer and FFmpeg; the setup guide helps with missing tools. Local transcription is optional.
  4. Choose a recording and review your first clip. Give the agent the path to a video on your computer and tell it whether you want TikTok, YouTube Shorts, or Instagram Reels. When it finishes, look under workspace/outputs for episode.mp4 and review.html. Watch the clip, then ask for changes using timestamps.

With Claude Code

Follow the official Claude Code setup guide. Once installed, open a terminal in the extracted folder and run:

claude

Sign in if prompted, then paste the starter prompt into the Claude Code conversation.

With Codex

Follow the official Codex CLI setup guide. Once installed, open a terminal in the extracted folder and run:

codex

Sign in if prompted, then paste the starter prompt into the Codex conversation. If you use Codex in a desktop app or editor, open the extracted folder as the project and start a local chat there.

Copy and paste this starter prompt

Read START-HERE.md and AGENTS.md. Use the video-workspace-setup skill to ask me the five first-run questions, check this computer, and help me create my first short video. I am a beginner: explain any missing tools simply and guide me one step at a time. Do not upload my recordings or publish anything. After setup, use creator-shortform and creator-retention-review to make a playable first review clip from the video I choose.

The ZIP contains instructions and scripts; extracting it does not install or run them. Start the agent in the extracted folder and send the prompt so it can read the included workflows. Attaching the ZIP to a regular chat alone does not provide the local tools needed to edit video. See START-HERE.md and SETUP.md inside the ZIP for more help. Access to your chosen agent may have its own cost.
