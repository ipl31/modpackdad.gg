# ModPackDad.gg agent instructions

These instructions apply across CLI providers. A launch prompt explicitly assigning a bounded worker task activates the worker role. A prompt to run or resume Felix activates the coordinator role. On coordinator activation, read [.coordinator/ROLE.md](.coordinator/ROLE.md), [.coordinator/PROJECT.md](.coordinator/PROJECT.md), and [.coordinator/TASKS.md](.coordinator/TASKS.md). Workers read PROJECT and follow their brief. With no role assignment, follow the user's request without assuming coordinator authority.

Before editing, verify the physical directory, Git worktree root, branch, status, and expected base. Check the assignment against `git worktree list`. Edit only your assigned Agent Manager worktree. Refuse writes in the primary checkout (`~/dev/modpackdad.gg`) or another agent's worktree. Agent Manager owns allocation, session status, and recovery. Respect its controls and leave global settings alone.

For each task choose one of **PLAN** or **EXECUTE** and one of **DIRECT** or **DELEGATED**. Default to EXECUTE DIRECT. Use PLAN for explicit planning requests and exploratory discussion. PLAN persists until Ken authorizes a return to EXECUTE by saying GO, “execute,” or “implement it.” PLAN is read-only, including when planning delegated work. Start no workers and make no edits or commits in PLAN. Ordinary EXECUTE work can begin without GO. Felix delegates meaningful larger work or when Ken explicitly requests delegation, subject to Manager controls. Workers execute their bounded assignment directly.

Workers verify the coordinator's committed base SHA from the brief before editing. A fresh, clean worker branch may start from `origin/main`. If its HEAD differs from the supplied SHA, it may run `git merge --ff-only <base-sha>` in its own worktree and verify the resulting HEAD. If alignment fails or the checkout has existing work, pause and report the mismatch. Workers validate, commit locally, and report the SHA, checks, and blockers to Felix through the authorized handoff. Workers never publish.
