Technique

Cues for each category

Pasu / Popcorn

Read target → acquire → brief confirmation → click. Do not increase click rate by spamming misses.

Static

Fast initial movement → brake → micro-correct → click.

Tracking

Stay relaxed and react to direction changes instead of predicting them.

Target switching

Flick → micro-correct → stabilize → move to the next target.

Sunday

Use the session as a diagnostic. Track typical-run improvement rather than chasing personal bests.

Setup

Local playlist installation

Copy the seven JSON files into the Kovaak's Playlists folder

<Steam library>\steamapps\common\FPSAimTrainer\FPSAimTrainer\Saved\SaveGames\Playlists

Restart Kovaak's if it is already running. The playlists should appear under Local Playlists.

  • Keep the listed difficulty for the full week.
  • If a scenario is missing, search for its exact name in Online Scenarios, download it, and retry the playlist.
  • Most scenarios are approximately one minute; exact session length varies.
