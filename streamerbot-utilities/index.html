Streamer.bot Giveaway List

v0.4.1

Run !giveawaylist to fetch the complete Twitch chat roster, save a clean timestamped list, and post the usernames in chat when the list fits.

  • Fetches the Twitch chat roster on every command
  • Includes connected silent chatters
  • Sorts and removes duplicate login names
  • Writes one username per line
  • Keeps timestamped giveaway history
  • Never exports a partial or stale roster
  • Supports space or comma chat delimiters
  • Posts short lists directly to Twitch chat
Download v0.4.1 View on GitHub Release Notes
Requirements: Streamer.bot 1.0.4 or newer and a connected broadcaster token with moderator:read:chatters. Re-import the downloaded action over the existing version.
